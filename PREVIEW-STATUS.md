# Electron Studio status

The active application is Electron 41.2.1 with the approved BitCrush Studio layout. Tauri is abandoned; its earlier source and reports remain as historical material. The original Downloads application is not used as a build directory or modified.

The Studio shell embeds the original renderer's controls, canvas, effect graph, history, timeline, media/export handlers and dialogs. It adds a searchable left style/palette library, preset library, center workspace, right inspector, header actions and dark/light appearances. The exact original compiled 73-algorithm engine runs in an Electron worker. The exact halftone bytecode runs in a hidden local Chromium renderer because it requires OffscreenCanvas. Each host checks the original module hashes before loading. The visible renderer remains sandboxed, with node integration disabled.

The offline edition starts directly in the workspace. It initializes local edition status before callbacks are created, so preset loading works immediately. No activation module is distributed. About/Licenses tabs, theme galleries and cat branding are removed from the displayed workspace. Dependency notices remain distribution files. Application settings and palette files use a separate BitCrush data directory.

Validation is recorded by `npm test` in `test-results/electron-smoke.json`. Engine coverage includes all 73 processors, 72 deterministic pixel comparisons against unchanged bytecode in the same Electron runtime, and three halftone comparisons. Windows workflow checks pass for image import, style/palette selection, native palette ZIP import, PNG/JPEG/WebP/SVG/clipboard export, preset save/export/load/import, the effect picker and pipeline editor, CMYK screen export, transform Undo, batch processing, preferences, light appearance, image animation MP4 export, video playback/export with a decoded 160×96 video and audio track, and timeline session export/import. These checks are bounded fixtures, not every possible media file and parameter combination.

Compatibility fixes retain media transform snapshots through graph/preset edits, initialize offline edition status before callbacks capture it, and validate MP4 containers instead of rejecting valid encodes below an arbitrary 10 KB threshold. The compiled processing modules remain byte-identical. The ZIP library used by native palette imports is updated to 0.6.1. Electron remains pinned to the compatible 41.2.1 runtime; the broader npm audit still reports advisories for that runtime and its development download dependencies.

Run 39532481237 passed on Windows x64, Intel Mac and Apple Silicon Mac. All 18 checks passed in both the source application and the copied packaged application on each platform. Both Mac bundles passed deep/strict signature verification. The codec corresponding-source job also passed. These are Electron-host results, independent of the historical Tauri previews. The run and downloadable artifacts are at https://github.com/thomastt-cryoo/BitCrush/actions/runs/39532481237 .

Full Electron ZIPs replace the abandoned 20 MB packaging limit. macOS packages are ad-hoc signed development builds; Apple notarization and installer signing are not part of these artifacts. Platform packages and checksums are stored in the workflow artifacts. Local downloads are under artifacts/github/electron-run12-intel and artifacts/github/electron-run12-arm. Windows was also verified locally from its copied executable, and the ZIP's integrity, engine hashes and single codec payload passed inspection.
